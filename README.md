# Nepali Number to Words — PWA

Free, installable web app that converts numbers into words in **Nepali (Unicode)**
and **English** (Nepali numbering system: thousand · lakh · crore · arab · kharab),
with paisa support for decimals.

## Features

- ⚡ Instant conversion as you type (no page reloads)
- 🇳🇵 Nepali Unicode output + 🇬🇧 English output side by side
- 📋 One-tap copy buttons for both results
- 💰 Paisa support — decimals up to 2 places
- 📲 Installable PWA — works fully offline after first visit
- 📱 Mobile-first, fully responsive design
- 🔍 SEO / GEO / AEO optimized (meta, Open Graph, JSON-LD WebApplication + FAQ schema)
- 🚀 Zero dependencies — no frameworks, no external requests

## Run locally

Just open `index.html`, or serve it:

```bash
npx serve .
```

## Deploy

Static files — deploy anywhere (Vercel, Netlify, GitHub Pages).
